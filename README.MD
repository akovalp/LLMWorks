
# Repository for Replicating LLM-Related Works

In this repository, I will provide the code to replicate the results of some interesting recent papers that explore how to utilize large language models for simulating different human behaviors. 
## Papers

1. **"Using Large Language Models to Simulate Multiple Humans and Replicate Human Subject Studies"** by Gati Aher, Rosa I. Arriaga, and Adam Tauman Kalai (2023)

   The replication will involve applying the methodology to simulate each experiment using the GPT-3 API. While API costs impose limitations on large-scale runs, the code will showcase the approach and allow for the reproduction of small-scale experiments. The prompts and outcome parsing will be designed to closely match the original paper.

   [Arxiv Link](https://arxiv.org/abs/2208.10264)

2. **"Can AI Language Models Replace Human Participants?"** by Danica Dillion, Niket Tandon, Yuling Gu, and Kurt Gray (2023)

   In the original paper, the authors reviewed evidence regarding whether large language models (LLMs) like GPT-3 can simulate human judgment and serve as substitutes for human participants in psychological research.

   [Paper Link](https://nikett.github.io/gpt-as-participant/)
