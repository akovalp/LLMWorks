# Repository for replicating LLM related works

In this repository, I will provide the code for replicating the results in some of the interesting recent papers on how to utilse large language models for simulating different behaviours of humans.

## Papers

### Using Large Language Models to Simulate Multiple Humans and Replicate Human Subject Studies" by Gati Aher, Rosa I. Arriaga, and Adam Tauman Kalai (2023)

The replication will apply this methodology to simulate each experiment with the GPT-3 API. While API costs limit large-scale runs, the code will demonstrate the approach and allow small-scale experiments to be reproduced. The prompts and outcome parsing will be designed to match the original paper as closely as possible.

[https://arxiv.org/abs/2208.10264](Arxiv Link)

### Can AI language models replace human participants?" by Danica Dillion, Niket Tandon, Yuling Gu, and Kurt Gray (2023)

 In the original paper, the authors reviewed evidence on whether large language models (LLMs) like GPT-3 can simulate human judgment and serve as replacements for human participants in psychological research.

 [https://nikett.github.io/gpt-as-participant/](Paper Link)
